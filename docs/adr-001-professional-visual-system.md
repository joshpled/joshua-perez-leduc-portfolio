# ADR 001: Professional visual system

- Status: Accepted
- Date: 2026-09-11

## Context

The first portfolio version used a dark, acid-green editorial direction. It was distinctive, but its visual intensity competed with the evidence a prospective client or hiring manager needs to evaluate quickly: services, project scope, engineering decisions, and trustworthy claims.

## Decision

Use a restrained consulting-style system built around deep navy, white, cool gray, and cobalt. Present the two strongest projects as structured case studies with challenge, solution, verified functionality, and technology. Keep the remaining work in consistent evidence-led cards. Preserve the single-page architecture and verified project-owned imagery.

## Why

The new system improves scanning, hierarchy, and perceived reliability while keeping a clear point of view. It also makes technical detail easier to read and gives calls to action an obvious but controlled emphasis.

## Alternatives rejected

- Keep the neon theme and only refine spacing: this would not change the site's dominant impression enough.
- Use a generic developer-terminal aesthetic: it communicates implementation but weakens product and consulting credibility.
- Add testimonials or performance metrics: no verified source material currently supports those claims.

## Consequences

The site feels less experimental and more appropriate for business-facing freelance work. Its credibility still depends on project evidence rather than client logos, testimonials, or invented outcomes. Public contact information remains a deliberate placeholder until approved by the owner.
