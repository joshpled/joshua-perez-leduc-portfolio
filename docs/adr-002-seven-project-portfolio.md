# ADR 002: Seven-project portfolio lineup

- Status: Accepted
- Date: 2026-09-11

## Context

The professional portfolio initially highlighted five projects, including older game-mod and research work. The owner selected a new seven-product lineup that better represents the practice they want prospective clients to evaluate: Boothline, Gatherroll, Wedding Dashboard, Builtproof, Lanes, When, and Noir.

## Decision

Keep Boothline and Gatherroll as the two expanded case studies because they have verified project-owned visuals and clear end-to-end product stories. Present Wedding Dashboard, Builtproof, Lanes, When, and Noir as compact evidence cards in a balanced two-plus-three desktop grid. Use explicit maturity labels for concepts, prototypes, and in-progress products.

## Why

The selected work shows a coherent range of current product engineering: event experiences, operational coordination, trade-business workflows, personal finance, native iOS, and cross-platform mobile. Two narrative case studies preserve depth, while five compact cards add breadth without making the page repetitive or difficult to scan.

## Alternatives rejected

- Expand all seven projects: this would create a long, repetitive page and would require more verified imagery than the projects currently provide.
- Present seven identical cards: this would flatten the strongest visual stories and reduce the portfolio's editorial hierarchy.
- Imply every product is production-ready: repository evidence does not support that claim for Boothline, Lanes, or Noir.

## Consequences

The portfolio now reflects the owner's preferred project set and removes older work from the primary narrative. Future updates must preserve the distinction between verified functionality and product maturity. Gatherroll is the public portfolio name for the existing wedding-camera project.
